# Contributing

Contributions that improve flight-simulator hardware integration, firmware, wiring documentation, or reproducibility are welcome.

## Guidelines

- Document the simulator, controller board, interface software, and relevant firmware versions.
- Keep pinout, HID, encoder, display, and protocol changes reproducible.
- Do not commit credentials, private keys, tokens, serial numbers, or machine-specific secrets.
- Include reproduction steps for input, display, connection, or calibration issues.
- Update documentation when supported hardware or dependencies change.

Pull requests should explain what changed, why it is useful, and how the change was validated.
